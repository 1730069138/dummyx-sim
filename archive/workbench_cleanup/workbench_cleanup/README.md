# 工作台中部圆弧清理任务

单臂先在工作台一侧（Y < 0）抓取海绵，将海绵绕桌面法向转约 60°，放到过渡点 XY=(0.450, -0.050) m，松爪并确认海绵稳定留在桌面；抬高末端后让第 6 关节绕工具轴转 180°，使腕部相机处于夹爪上方，再夹住同一手柄短轴，然后在另一侧（Y > 0）把三块泡沫碎屑扫入悬在桌边外侧的接料盘。清扫轨迹都以机械臂 `link0` 基座投影为圆心：第一遍半径 0.460 m、角度 −15° 至 +75°；仅当第一遍后仍有碎屑未落盘，才执行半径 0.500 m、角度 +25° 至 +75° 的补扫。每遍后重新检查，最多补扫四次。第一段在 Y=0 处经过 X≈0.589 m，桌面中心为 X≈0.711 m；海绵垫有 90 mm 宽，因此接触区伸向桌面中部。第二次抓取后至海绵放回桌面期间，相机中心始终高于两侧夹指，清扫期间保持双指夹持，末端偏航角随圆弧角度同步转动，海绵长边与圆弧径向约差 15°，接近横跨清扫方向；补扫之间抬起并重新定位，不放下或焊接海绵。确认全部落盘后才将海绵放回桌面原取用区附近（目标 XY=(0.415, -0.160) m），张开夹爪，再返回 `models/agv_dummyx/z_pose.json` 定义的 Z 型姿态。

- `scene.xml`：无杯采集场景。
- `task_props.xml`：海绵、三块可运动泡沫碎屑、固定悬空接料盘。
- `scene_cup.xml`、`cup.xml`：杯子放在第一段圆弧中部的固定初态评估场景；采集脚本不会加载它。
- 机械臂、AGV、相机和工厂模型沿用上层目录；新增道具用 MJCF 基本几何体构成。

海绵垫为 90 × 120 × 12 mm，手柄为 22 × 60 × 20 mm。夹爪沿手柄的 X 短轴夹持，下降前开口 55 mm，手柄两侧各有约 16.5 mm 名义余量。三块碎屑各约 8 × 8 × 6 mm。仿真以柔软接触参数近似海绵，没有建模海绵内部形变。

桌面近边为 X=0.360976 m，盘体最近边为 X=0.358 m，水平间隔约 3 mm。接料盘占据 X∈[0.272, 0.358] m、Y∈[0.310, 0.530] m，盘底顶面 Z=0.755 m，低于桌面 Z=0.800 m。初态盘体与 AGV 碰撞模型的最近距离约 0.109 m，固定初态清扫阶段海绵垫与 AGV 底座碰撞模型的最近距离约 0.181 m。盘体在仿真中固定，未画支架；实机使用时需固定在桌边外侧。

## 运行

在仓库根目录先试一集：

```bash
conda activate dummyx_vla
python archive/workbench_cleanup/collect_workbench_cleanup.py \
  --num_episodes 1 --max_attempts 1 --seed 42 --fixed_eval --realtime
```

随机初态采集：

```bash
python archive/workbench_cleanup/collect_workbench_cleanup.py \
  --num_episodes 50 --seed 42 --realtime
```

默认输出至 `datasets/agv_dummyx_workbench_cleanup_regrasp/`。海绵初始 XY 在 ±12/15 mm 内随机，碎屑各自 XY 在 ±3 mm 内随机；`--fixed_eval` 固定初态。`--headless` 使用 EGL 离屏渲染并保存图像，`--no_images` 仅用于物理诊断。采集无需 OpenPI 服务。

## 数据与边界

成功回合的 `ep_XXXX/` 保存固定相机 640×360、腕部相机 256×256 的 RGB JPG、`joint_data.npz`、`metadata.json` 和 `instruction.txt`，频率 50 Hz。7 维状态与动作是六关节角（rad）和夹爪总开口（m）；动作是下一段 20 ms 的绝对位置目标。失败回合保存在 `failures/`，每次运行的结果保存在 `runs/`。

成功要求海绵在过渡点放稳并松爪、腕部实际转约 180° 后重新夹稳手柄、相机中心从再次抓取到放回海绵始终比两侧夹指中心高至少 5 mm、三块碎屑完整落入悬空盘并低速静止、海绵放回目标区域并稳定留在台面、夹爪张开、六关节回到 Z 型姿态（最大角度误差 <0.04 rad），且机器人本体与附件未出现超过 1 mm 的桌面穿透。这里的“相机在上方”约束指相机与夹指的空间高度关系，不要求相机光轴竖直向上。默认最多尝试目标成功回合数的十倍，达不到目标时返回非零退出码。修改后，固定初态 1/1 和随机初态 seed 42 的 3/3 次尝试均完成全部任务，且在第一遍后全部落盘，补扫次数为 0，随后完成海绵归位和回 Z。固定初态腕部翻转约 179.6°，再抓取时相机中心高于两侧夹指约 26 mm，再抓取后的整个动作中最低约 26 mm。诊断中将一块碎屑刻意移远时，脚本执行了四次补扫；仍未清空则记录失败，海绵不归位。失败样本仍会保存，正式采集仍需检查成功率。

`pad_table_impulse_ns`、`debris_table_impulse_ns` 和 `table_impulse_ns` 是 MuJoCo 每个物理子步法向力积分的仿真真值，供离线评价。动作生成使用目标几何位置，不读取接触求解器的力值。整回合接触冲量含静置支撑载荷；论文比较清扫接触时可分别使用 `contact_impulses_by_phase.sweep_1` 以及实际执行的 `sweep_2`、`sweep_3` 等补扫阶段。海绵软接触仅是仿真近似，不能将该法向力直接当作实机电流推算的接触力。

数据 schema 为 `agv_dummyx_workbench_cleanup_arc_v9`；现有螺丝刀专用 LeRobot 转换器不接受这个 schema。带杯场景只用于后续避障评估，尚未运行避障推理。
